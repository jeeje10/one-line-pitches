A one-sentence pitch for make.fun's "A Day of One-Line Pitches" bounty: the sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. main.ts writes the sentence (204 characters) to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
